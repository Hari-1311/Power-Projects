📊 Sales Analysis Dashboard - Power BI

📌 Project Overview

The Sales Analysis Dashboard is an interactive Power BI solution designed to analyze sales performance and profitability across products and time periods.

The dashboard helps stakeholders monitor business performance and identify opportunities for growth through data-driven insights.

---

🎯 Objectives

- 📈 Track overall sales performance
- 💰 Monitor profit and profit margins
- 📦 Analyze product-wise revenue contribution
- 🔍 Enable interactive exploration through drill-through and tooltips

---

🛠️ Tools & Technologies

- 📊 Power BI – Dashboard development and data visualization
- 🔄 Power Query – Data cleaning and transformation
- 🧮 DAX – Business calculations and KPI development
- 🗂️ Data Modeling – Optimized Star Schema data model

---

⭐ Key Features

- 🎴 Interactive KPI Cards
- 🔎 Drill-through Navigation
- 💡 Dynamic Tooltips
- 🔄 Data Transformation using Power Query
- 🧮 DAX Measures for Business Calculations
- ⭐ Optimized Star Schema Data Model

---

📌 Key KPIs

- 💵 Total Revenue
- 💰 Total Profit
- 📊 Profit Margin

---

💼 Business Benefits

- 📊 Provides a centralized view of sales performance
- 💡 Helps identify profitable products
- 📈 Supports data-driven decision-making
- 🔍 Enables quick access to detailed insights through drill-through functionality
